# Museum of the Year 3000

Entry for [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb)
on make.fun — one line, at most 200 characters: the museum label a museum
in the year 3000 puts beside an ordinary object from today.

## The label (116 characters)

> Terms and conditions, c. 2024. A sacred scroll, ten thousand words long. Every human agreed to it; none had read it.

## Why this label

- **Reads like a real museum label:** object, circa date, then the
  description — short, straight faced and confident, in one line.
- **The humour is the misreading:** terms and conditions, a text every
  human agreed to and nobody read, catalogued as a sacred scroll —
  something true and absurd about what the thing was for.
- **The joke lands on a first read:** "ten thousand words long" is a
  concrete, deadpan detail, and the punchline sits in the last clause
  with no explanation around it.
- **Fresh object and angle:** not the obvious fork, key or meter, and
  the angle — a legal text treated as a ritual object — is not the
  first joke anyone tells about it.

## How it runs

`main.ts` (Node, standard library only) writes the label to
`/output/entry.txt`. Run locally with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
